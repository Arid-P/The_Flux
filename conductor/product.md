# Project Name
The_Flux

## Description
An offline-first Android productivity and screen discipline app built with Flutter, focused on strict app blocking and time‑blocking via Accessibility Services.

## Problem Statement
Passive wellness apps lack the friction needed to prevent distraction. This project solves that by enforcing strict screen discipline through mechanical flip‑clock focus sessions, YouTube Study Mode whitelists, and 2/5/10/20 minute intervention overlays.

## Target Users
Students and individuals undertaking high‑stakes, intense academic workflows (such as IOQM, INMO, or JEE Advanced preparation) who require absolute focus and accountability through a streak‑based system.

## Key Goals
- **Goal 1:** Strictly enforce the offline‑first architecture using SQLite, Hive, and Riverpod 3.x, alongside the Android MethodChannel IPC bridge.
- **Goal 2:** Maintain strict adherence to the flat 2D "Rustic Medley" design system across all generated UI components.
- **Goal 3:** Seamlessly coordinate tasks between the Flutter/UI agent (Code1) and the Tailwind mockup agent (Code2) while maintaining the centralized agent worklog.
